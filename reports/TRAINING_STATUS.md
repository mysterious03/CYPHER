## 2. In-Depth Training Analysis

### 2.1 Model M1: YOLO26n Road Damage (B0 Baseline)
- **Training Strategy:** Fine-tuned from `yolo26n.pt` on RDD2022 India for 38 epochs with AdamW optimizer, cosine annealing, and Automatic Mixed Precision (AMP).
- **Batch Size / Resolution:** Batch size 4, input resolution $640 \times 640$.
- **Convergence Behavior:** Box loss dropped from 1.98 to 1.12; classification loss converged to 0.65.
- **Holdout Validation:** Evaluated on the 1,172 untouched images:
  - Overall Precision: **59.53%**
  - Overall Recall: **28.60%**
  - mAP@50: **27.71%**
  - mAP@50-95: **13.16%**
  - Alligator Crack (`D20`) mAP50: **53.19%**
  - Pothole (`D40`) mAP50: **33.48%**
  - Longitudinal Crack (`D00`) mAP50: **23.08%**
  - Transverse Crack (`D10`) mAP50: **1.07%** (0 True Positives due to 30x dataset sparsity).

### 2.2 Model M2: Multi-Task Surface Classifier
- **Training Strategy:** Trained MobileNetV3-Large with three parallel linear heads for 5 epochs using CrossEntropy loss with label smoothing (0.05) and AdamW ($\text{lr} = 1e-3$).
- **Batch Size / Resolution:** Batch size 32, input resolution $224 \times 224$.
- **Validation Results:**
  - Friction State Accuracy: **98.67%**
  - Surface Material Accuracy: **100.0%**
  - Surface Unevenness Accuracy: **95.0%**
  - Mean Validation Accuracy: **97.89%**

### 2.3 Model M3: Waterlogging Segmenter Audit
- **Audit Truth:** The legacy 30.76% IoU model was trained on **heuristic synthetic pseudo-masks** (`_generate_heuristic_water_mask`) generated by thresholding dark specular pixels and sky glare, rather than human-annotated ground-truth masks.
- **Remediation:** Pipeline initialized in `data/processed/water_authentic/` with `authentic_water_dataset.py` to ingest real pixel annotations from R²S100K and retrain the model for 15 epochs.
